# ZeroLoop
An IBM Bob pre-flight intelligence tool that scans Node.js 
projects for dependency conflicts, version mismatches, 
and circular dependencies before Bob starts any task.
The goal is to eliminate Bob's token-wasting retry loops
by giving Bob complete situational awareness upfront.

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Python 3 (scanner engine)
- Framer Motion (animations)
